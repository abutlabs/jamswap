# Watching runs live

The observability stack every jamswap net and soak reports into is its own repository,
[abutlabs/observability](https://github.com/abutlabs/observability) (in the parent repo:
`submodules/observability`, which `./dex` finds as `../observability`; set `OBS_HOME`
otherwise). Its README has the architecture, the ports and how projects plug in.

```sh
./dex obs up              # the stack's own CLI, through ./dex
open http://localhost:3300
```

How jamswap plugs in:

- **Labels.** Every service of every net carries `org.abutlabs.obs.*` labels
  (`nets/netgen.py` writes them into the generated compose files; `docker-compose.lasair6.yml`
  and `docker-compose.mixed.yml` carry them by hand). The stack scrapes the lasair nodes
  (`:9615`), the dex (`:8080`), the load generator (`:9111`), netwatch (`:9106`) and lasair's
  builder (`:19980`); polls the JIP-2 RPC of the PolkaJam nodes and of each lasair node's
  reader; and collects every container's logs.
- **Runs.** `./dex up NET=<net>` gives the net's containers a fresh run id (`OBS_RUN_ID`, a
  re-up keeps the running net's), annotates the start and prints the dashboard links;
  `load`, `noload`, `soak` and `down` annotate the run. PolkaJam nodes send JIP-3 telemetry
  to the stack's receiver when `OBS_JIP3` is set. Without the stack, `up` prints one line
  and the net runs as before.
- **Soaks.** `nets/soak.py` pushes its configuration, its progress every minute and its
  verdict to the stack's Pushgateway under the run id (`nets/soak_metrics.py`).
- **Dashboards.** jamswap's own are in `observability/dashboards/` (Grafana folder
  "jamswap"), generated by `observability/gen_dashboards.py`: **DEX** and **Soak runs**.
  The cross-client ones (network overview, chain health, logs) are the stack's, and
  lasair's (validator duties, memory) are in lasair's repository.

The older per-net overlays (`docker-compose.monitor.yml` on the mixed net,
`docker-compose.lasair6-monitor.yml`; Grafana `:3010`) and the dashboards in
`monitor/grafana/` still work for those two nets.
